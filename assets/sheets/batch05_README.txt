OPERATION: LOST FRONTIER — BATCH 05

Contains one high-resolution PNG composite atlas with:
- Jungle, desert, snow, urban, factory, and alien environment concepts
- Terrain tiles and platform pieces
- Structures, props, vehicles, and machinery
- Traps, obstacles, power-ups, and items
- UI elements and level effects

Note: This is a composite reference atlas. It is not a set of individually
cropped production-ready sprites. The checkerboard and section labels are
part of the generated image. Slice and clean individual elements before
importing them into Unity or another game engine.
