Unity usage:
- This is a composite concept atlas, not 20 separate 16:9 background files.
- Crop each cell into its own image before importing as a Unity Sprite.
- The generated title labels and panel borders are part of the artwork.
- For production parallax backgrounds, create separate clean layers for
  far background, midground, and foreground.
